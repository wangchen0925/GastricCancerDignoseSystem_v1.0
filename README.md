# 胃癌基因智能诊断系统

基于基因表达谱与机器学习（随机森林特征筛选 + 人工神经网络分类）的胃癌智能诊断系统。系统采用 **Lambda 架构**：批处理层负责全量数据训练并保存模型，服务层提供 Web 上传与实时诊断。

## 功能特性

- **智能诊断**：上传基因表达数据，自动判断样本为「胃癌阳性」或「胃癌阴性」，并给出阳性概率
- **多格式支持**：支持 CSV / TSV / TXT 格式上传，可手动选择分隔符
- **随机森林特征筛选**：基于 Gini 重要性筛选核心特征基因（20 个），降维去噪
- **ANN 诊断模型**：单隐层（5 节点）logistic 神经网络，与 R 版实现 1:1 复刻
- **双语言实现**：提供纯 Python 版（`model.py`）与 R 版（`code.R`）训练代码，结果互通
- **历史记录**：Web 界面自动保存本次会话的全部诊断记录

## 快速开始

### 环境依赖

- Python 3.8+（Web 服务与 Python 版训练）
- R 4.x（可选，仅运行 R 版训练脚本时需要）

```bash
# Python 依赖
pip install flask pandas numpy scikit-learn joblib plotly

# R 依赖（可选）
# R 包：randomForest, caret, limma, neuralnet, jsonlite
```

### 启动诊断服务

```bash
python gastric_app.py
```

浏览器访问 **http://127.0.0.1:5000**，上传基因表达文件即可诊断。

### 重新训练模型（可选）

`model/` 目录已包含训练好的模型，一般无需重训。如需用新数据重训：

```bash
python model.py      # 纯 Python 版
# 或
Rscript code.R       # R 版
```

训练完成后自动覆盖 `model/` 下的模型文件。

## 数据格式说明

### 上传文件格式（服务层输入）

```
        样本1    样本2    样本3      ← 第一行为样本ID
基因A   2.781    1.905    3.264     ← 每行一个基因
基因B   4.616    2.214    2.595
...      ...      ...      ...
```

- **行 = 基因，列 = 样本**；第一列为基因名，第一行为样本 ID
- 支持 CSV（逗号）/ TSV、TXT（制表符）分隔，上传时选择
- 文件大小上限 16MB
- 必须包含全部 20 个特征基因（`model/rf_genes.csv`），缺失将报错并提示

### 训练数据格式（批处理层输入）

| 文件 | 说明 |
|------|------|
| `diffGeneExp.txt` | 差异基因表达矩阵，行=基因、列=样本（`GSM编号_分组` 命名，分组取 `_` 后第二位：con/treat） |
| `diff.txt` | limma 差异分析结果，含 `logFC` 列（>0 上调，<0 下调） |

## 诊断原理

1. **特征提取**：按训练时固定的基因顺序提取上传样本的 20 个特征基因表达量
2. **二值化评分**：上调基因「表达量 > 中位数 → 1」，下调基因「表达量 > 中位数 → 0」，构建 0/1 特征矩阵
3. **ANN 预测**：MLPClassifier（单隐层 5 节点，logistic 激活）输出阳性概率
4. **结果判定**：概率 ≥ 0.5 判定为「胃癌阳性」，否则为「胃癌阴性」

> 预测端的特征工程（基因顺序、中位数阈值、缺失值处理）与训练端 1:1 一致，保证特征对齐。

## 注意事项

- `gastric_app.py` 中工作目录 `WORK_DIR` 为 `F:/gastric_diagnose`，若项目迁移需同步修改
- 诊断记录保存在内存中（`diagnosis_records`），重启服务后清空
- 上传数据缺失特征基因时，系统会列出缺失基因前 10 个并提示排查方向
- 含缺失值（NaN）的样本会被自动剔除，不影响其余样本诊断
